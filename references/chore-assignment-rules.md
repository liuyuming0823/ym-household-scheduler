# 家务分配规则

## 能力分档标准

| 档位 | 年龄范围 | 体力 | 判断力 | 可承担范围 |
|------|----------|------|--------|------------|
| 成人 | 18岁以上 | 强 | 完全自主 | 全部家务 |
| 青少年 | 12-17岁 | 中等 | 基本自主 | 日常轻量+日常中量，可协助周期重活 |
| 儿童 | 6-11岁 | 较弱 | 需指导 | 日常轻量为主，简单中量需监督 |
| 幼儿 | 6岁以下 | 不足 | 不足 | 不参与轮值，可做简单收纳（不计入） |

## 轮值规则

### 周轮换

- 以周为单位，每周轮换成员负责的家务项
- 适合日常轻量和日常中量
- 周末统一调整下周轮值表
- 示例：本周A做饭+B洗碗，下周A洗碗+B做饭

### 月轮换

- 以月为单位轮换
- 适合周期重活
- 每月初调整当月安排
- 示例：1月A负责厨房深度清洁，2月B负责

### 固定+轮换混合

- 固定项：某人固定负责（如擅长烹饪者固定做饭）
- 轮换项：在成员间轮换（如洗碗轮换）
- 适合有明确偏好的家庭
- 固定项计入公平性统计，需通过轮换项平衡

## 公平性校验公式

### 总工作量均衡

```
各成员每周家务总时间偏差 = (最大成员时间 - 最小成员时间) / 平均时间
要求：偏差 < 15%
```

### 难度加权

```
各成员每周难度总分 = Σ(各项家务难度系数 × 频率)
各成员难度偏差 = (最大难度分 - 最小难度分) / 平均难度分
要求：偏差 < 20%
```

### 校验表

| 成员 | 每日轻量时间 | 每日中量时间 | 周期重活时间 | 总周时间 | 难度总分 | 时间偏差 | 难度偏差 |
|------|-------------|-------------|-------------|----------|----------|----------|----------|
| | | | | | | | |
| | | | | | | | |

判定：□ 时间偏差<15% □ 难度偏差<20% → □ 公平 □ 需调整

## 偏好处理方法

1. **收集偏好**：记录每个成员的擅长项和厌恶项
2. **擅长项优先匹配**：擅长烹饪者优先分配做饭
3. **厌恶项轮换**：厌恶洗碗者在成员间轮换，不长期固定给一人
4. **偏好冲突处理**：多人擅长同一项时，按轮换周期分配；多人厌恶同一项时，缩短轮换周期（如从周轮换改为日轮换）
5. **偏好调整**：每月回顾偏好变化，成员可能产生新的擅长或厌恶项
